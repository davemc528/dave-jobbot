# Next Phase Outline

The following items are intentionally deferred beyond Phase 1:

- JobSpy integration for external posting ingestion and deduplication
- Robust Greenhouse, Lever, and Workday adapters with site-specific selectors
- Resume DOCX/PDF generation from verified profile facts
- Email and calendar integration for candidate follow-up and interview scheduling
- Optional final-submit capability that requires a separate explicit user confirmation
- Metrics and reporting for application quality, interview yield, and conversion rates
